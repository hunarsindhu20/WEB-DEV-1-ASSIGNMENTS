# Personal Portfolio Webpage

A simple, responsive personal portfolio webpage built as an intro project for learning web development fundamentals.

## 👤 Author
**Hunar Sindhu**  
*Beginner Web Developer*

---

## 📌 Project Overview
This project serves as a starter portfolio website displaying essential sections such as:
- **About Me:** Brief introduction and profile photo.
- **Skills Table:** Current proficiency in HTML, CSS, and JavaScript.
- **Projects Showcase:** Highlights of mini-projects built during learning.
- **Contact Form:** Simple form interface for visitors to send messages.
- **Navigation:** Sticky top navigation bar and a quick "Back to Top" floating button.

---

## 📁 File Structure

```text
├── index.html        # Main HTML layout for the portfolio
├── style.css         # Styling, layout rules, colors, and typography
└── images/           # Assets directory
    └── me.jpg        # Profile image
```

---

## 🛠️ Technologies Used
- **HTML5:** Semantic markup, forms, tables, and anchor navigation links.
- **CSS3:** Sticky positioning, fixed elements, custom color scheme, styling tables, forms, and custom fonts (Roboto, Google Sans).

---

## 🚀 How to Run
1. Clone or download this project repository to your local machine.
2. Ensure you have your profile picture saved at `images/me.jpg` (or update the file path in `index.html`).
3. Open `index.html` directly in any web browser (Google Chrome, Firefox, Edge, Safari, etc.).
